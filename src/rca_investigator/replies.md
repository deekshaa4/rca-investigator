# CuteBot's small-talk replies

CuteBot answers everyday chat from this file, without the language model, so replies are
instant and never robotic. Each `##` section is one situation:

- `match:` words or phrases that trigger it (comma-separated, any case).
- each `-` line is one possible reply. CuteBot picks one it hasn't used recently.

Sections higher up win when a message matches several. Add or edit replies freely.
